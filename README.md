# crisrecorder

Screen recorder in a single page. Captures a screen, window, or tab with system and microphone audio, plays the result back, and hands you the file. Runs entirely in the browser: no video leaves your machine.

**[Open](https://criskell.github.io/crisrecorder/)**

## Run it locally

```
python3 -m http.server
```

Needs `localhost` or HTTPS. Works on desktop Chrome, Edge, and Firefox.
